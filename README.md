# AI play shop

Opgavekatalog til AI-eftermiddagen for undervisere på Markedsføringsøkonom og Serviceøkonom, Dania.

18 opgaver på tre hylder (Kom godt i gang, Øvet, Avanceret). Prisen er tiden. Hver opgave har mål, trin, en startprompt, der kan kopieres, og forslag til, hvor man går videre.

## Brug

Åbn `index.html` i en browser. Siden er én selvstændig fil uden byggetrin; den henter kun skrifttyper fra Google Fonts.

Facilitatorens tjekliste huskes kun i den enkeltes browser (localStorage).

## Indhold

Bygget på opgavebanken "AI-eftermiddag: Opgavebank i tre niveauer". Opgaverne ligger som data (`NIVEAUER`, `OPGAVER`, `SPILLEREGLER` m.fl.) i det første `<script>` i `index.html`, så de kan rettes uden at røre layoutet.
